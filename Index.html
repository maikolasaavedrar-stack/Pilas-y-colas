Método

Fórmulas y supuestos

Simulación de eventos discretos

Las llegadas se generan con tiempos exponenciales de media 1/λ (proceso de Poisson). Cada usuario toma el primer servidor libre en orden de llegada y su servicio sigue la distribución elegida. Se descarta el primer 10 % de la franja como calentamiento.

Modelo M/M/c

Wq = C(c, λ/μ) / (cμ − λ)
Lq = λ·Wq · W = Wq + 1/μ · L = λ·W

C es la probabilidad de esperar (Erlang C). La última relación es la fórmula de Little (1961).

Servicio no exponencial

Wq(M/G/c) ≈ Wq(M/M/c) · (1 + CV²) / 2

Exacta para un servidor (Pollaczek-Khinchine). Para varios servidores es la aproximación de Lee-Longton, por eso puede diferir un poco de la simulación.

Estabilidad y recomendación

  • El sistema es estable solo si ρ = λ/(cμ) < 1.
  • Costo total por hora = c · costo por servidor + λ · Wq · costo de espera.
  • Se recomienda el escenario de menor costo entre los que cumplen la espera aceptable.
  • Intervalo de confianza: media ± t0,975 · s/√n sobre las réplicas.
